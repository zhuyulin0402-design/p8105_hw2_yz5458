``` r
transit_df = read_csv("data/NYC_Transit_Subway_Entrance_And_Exit_Data.csv",
    show_col_types = FALSE) |>
  janitor::clean_names() |>
  select(
    line,
    station_name,
    station_latitude,
    station_longitude,
    route1:route11,
    entry,
    vending,
    entrance_type,
    ada
  ) |>

    entry = entry == "YES",
    across(route1:route11, as.character)
  )

  transit_df |>

  transit_df |>

  distinct(line, station_name) |>

  filter(vending == "NO") |>
  summarize(
    proportion = mean(entry, na.rm = TRUE)

transit_long =
  transit_df |>
  pivot_longer(
    cols = route1:route11,
    names_to = "route_number",
    values_to = "route_name"

  filter(!is.na(route_name))

n_a_stations =
  transit_long |>
  filter(route_name == "A") |>
  distinct(line, station_name) |>
  nrow()

  transit_long |>
  filter(
    route_name == "A",
    ada == TRUE
  ) |>
  distinct(line, station_name) |>
  nrow()
```

The cleaned NYC Transit dataset have the information about subway
station entrances and exits, including subway line, station name,
station latitude and longitude, routes served, whether entrance is
allowed, vending availability, entrance type, and ADA compliance.I
retained only the variables needed for the analysis, converted `entry`
from `"YES"` and `"NO"` to logical values, and converted all route
columns to character so they could be reshaped consistently.

The resulting dataset contains 1868 rows and 19 columns.

These data are not completely tidy, I think because the subway routes
are stored across multiple columns (`route1` through `route11`) instead
of being stored in a single route variable.

There are 465 distinct stations and there are 84 ADA-compliant stations.

Among station entrances and exits without vending, the proportion that
allow entrance is 0.377.

After reshaping the route variables, there are 60 distinct stations that
serve the A train. Of those stations, 17 are ADA compliant.

The baseline dataset was cleaned by skipping the descriptive first row,
treating missing values as `NA`, recoding sex and APOE4 status as
factors, and removing participants with MCI at baseline. The final
baseline dataset contains 479 participants; 93 developed MCI, the mean
baseline age is 65 years, and 0.3 of women are APOE4 carriers.

The amyloid data were reshaped from wide to long format so each row
represents one participant at one visit. There are 8 participants only
in the baseline data and 16 only in the amyloid data. After an inner
join, the final dataset contains `nrow(mci_complete)` rows and was saved
as `data/mci_complete.csv`.
